# Agentic Buying Standard (ABS) v0.1: superseded

ABS v0.1 (2026-11-04) was measured by Independent Audit 0 (`audits/AUDIT_0_THESIS.md`) and by the
rule-completeness simulation (`standard/sim/REPORT.md`, rule set `scrolld.abs@0.1`: 340 of 528
catalogue scenarios right, 8 gap types, 4 unresolved conflicts, 58 contradiction groups). Both sets
of findings are resolved in **`ABS_v0.2.md`**, which is the current document. The v0.1 rules remain
available as the simulation's `scrolld.abs@0.1` rule set for comparison.
